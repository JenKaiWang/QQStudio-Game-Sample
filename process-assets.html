Removes the white/light background from player.png, keeping only the ramen bowl character.

Instructions:

  1. For Player: Select player.png → Click "Process Player" → Download the result and save to assets/player.png
  2. For Obstacle: Select obstacle.png → Click "Split Obstacle" → Download both images to assets/obstacle-top.png and assets/obstacle-bottom.png
  3. For Obstacle Images: For each obstacle image (top and bottom), use "Remove White Background" tool:
    • Select assets/obstacle-top.png → Click "Remove White Background from Obstacle" → Download and save back to assets/obstacle-top.png
    • Repeat for assets/obstacle-bottom.png
  4. Refresh your game page. New assets will load automatically with proper rendering and no white backgrounds.
